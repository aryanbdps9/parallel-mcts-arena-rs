A multi-threaded Monte Carlo Tree Search engine that plays some classic board games with configurable AI opponents

Usage: play.exe [OPTIONS]

Options:
  -c, --cpu-exploration-factor <CPU_EXPLORATION_FACTOR>
          The exploration factor (C) for the MCTS PUCT formula (CPU) [default: 4]
      --gpu-exploration-factor <GPU_EXPLORATION_FACTOR>
          The exploration factor (C) for the MCTS PUCT formula (GPU) [default: 2]
  -s, --search-iterations <SEARCH_ITERATIONS>
          Maximum number of MCTS iterations per search [default: 1000000]
  -m, --max-nodes <MAX_NODES>
          Maximum number of nodes to store in the MCTS tree [default: 1000000]
  -n, --num-threads <NUM_THREADS>
          Number of parallel threads for MCTS search [default: 8]
  -g, --game <GAME>
          Pre-select a specific game to play on startup
  -b, --board-size <BOARD_SIZE>
          Board size for games that support variable dimensions [default: 15]
  -l, --line-size <LINE_SIZE>
          Number of pieces in a row required to win [default: 5]
      --timeout-secs <TIMEOUT_SECS>
          Maximum thinking time per AI move in seconds [default: 60]
      --stats-interval-secs <STATS_INTERVAL_SECS>
          Frequency of AI statistics updates in seconds [default: 20]
      --ai-only
          Enable AI vs AI mode with no human interaction
      --shared-tree
          Enable tree sharing between consecutive moves
      --gpu-threads <GPU_THREADS>
          Number of threads for GPU search batch size [default: 4096]
      --gpu-use-heuristic <GPU_USE_HEURISTIC>
          Use heuristic evaluation instead of random rollouts for GPU simulations [default: true] [possible values: true, false]
      --cpu-select-by-q
          Select moves by highest Q value instead of highest visit count (CPU AI)
      --gpu-select-by-q
          Select moves by highest Q value instead of highest visit count (GPU AI)
      --gpu-native-batch-size <GPU_NATIVE_BATCH_SIZE>
          Batch size for GPU-Native MCTS (Othello only) [default: 4096]
      --gpu-virtual-loss-weight <GPU_VIRTUAL_LOSS_WEIGHT>
          Virtual loss weight used by GPU-native MCTS (Othello). Higher values force wider exploration and reduce stampede collisions [default: 5]
      --gpu-temperature <GPU_TEMPERATURE>
          Temperature for softmax selection in GPU-native MCTS (Othello). Lower values make selection more greedy, higher values more random. Typical range: 0.01 (very greedy) to 1.0 (more exploratory) [default: 0.6]
      --gpu-vl-temp-scale <GPU_VL_TEMP_SCALE>
          Scaling factor for virtual-loss-based temperature boost. Higher values increase temperature dynamically when nodes have high VL (contention). Formula: effective_temp = base_temp × (1 + parent_vl × vl_weight × vl_temp_scale) Typical range: 0.001 (subtle) to 0.1 (aggressive) [default: 0.01]
      --gpu-max-nodes <GPU_MAX_NODES>
          Maximum nodes for GPU-native MCTS tree (Othello)
  -h, --help
          Print help (see more with '--help')
  -V, --version
          Print version
